# 用户使用指南

> 面向使用者说明系统功能与操作方式。功能范围与完成状态的权威清单见 `.project-to-act/PROJECT_FEATURES.md`；部署与运维见 [operations.md](operations.md)。

## 1. 系统是什么

一句话：**用自然语言把想法变成日程，用周计划与任务看板两个视图落地执行。**

- 在输入框里写一句话（如「周二下午2点到5点写代码，地点深圳湾」），系统自动生成时间块。
- 周计划视图做**时间管理**（7×24 小时时间轴），任务看板做**任务管理**（宏观目标 → 子任务 → 排期）。
- 记忆系统记住你的偏好与约束，让 AI 规划越来越贴合你。
- 数据默认保存在浏览器本地；登录后同步到 Supabase 云端。

### 数据在哪里

| 状态 | 说明 |
|---|---|
| 本地模式 | 未登录或未配置 Supabase。数据存在当前浏览器的 localStorage，换设备/清缓存会丢失 |
| 云端同步 | 登录账号后自动同步。顶部导航右侧显示「云端同步」 | 

首次打开没有数据时，系统会加载一份**展示数据**（左上角有「展示数据」标签），便于先逛一遍界面；之后新建的内容会替换掉它。

## 2. 界面总览

顶部导航（长期可见）：

- 四个视图页签：**今日 / 周计划 / 任务看板 / 统计周报**
- **撤销 / 重做**按钮（快捷键 `⌘Z`、`⇧⌘Z` 或 `Ctrl+Y`，历史 50 步；在输入框内打字时快捷键不生效，避免误触）
- **设置**（齿轮图标）、**登录/账号**、**同步状态**标识

每个视图有各自的副导航栏（上一周/本周/下一周、新建时间块、AI 规划等）。页面底部还有页脚快捷入口（视图、记忆系统、设置、云同步等），与顶部入口等效。

**弹窗通用操作**：所有弹窗（编辑、设置、登录、确认框、提示等）打开期间背景页面锁定滚动，滚轮只作用于弹窗内容；`Esc` 关闭最上层弹窗（叠着的弹窗按打开顺序倒序一层层关）；点击遮罩或右上角 × 也可关闭。

## 3. 周计划视图

### 3.1 自然语言建日程（QuickAdd）

周计划顶部的大输入框：

```
周二下午2点到5点写代码，地点深圳湾；周三上午10点健身
```

支持一次输入多件事（用分号隔开），支持：

- 相对星期（周二/明天/后天）、具体日期、「上午/下午/晚上」、`2点到5点`、`14:00-17:00` 等写法
- **地点**：`地点深圳湾`（独立解析到地点的字段）
- **类目**：根据事项内容自动归类（工作/学习/健身/生活/休息，如「写代码」→工作、「跑步」→健身），可在时间块弹窗里改
- **跨天**：`今晚10点到明早8点`（周计划里按天分段渲染）
- **关联任务**：`关联 X`（把生成的时间块绑定到任务 X，并从事项名里剔除「关联 X」这几个字）
- **截止日期**：`周五前` / `下周三截止`（匹配到任务时自动填入同名子任务的截止日期；匹配不到会弹窗引导你选择或新建任务）
- **完成指令**：`标记为已完成` / `已完成` / `已经完成`（补记已完成的事时，生成的时间块直接就是已完成状态，指令字样不会出现在事项名里；这类块不再设默认提醒；注意「完成报告」这类待办动作不会被当成完成指令）

点击「生成」后，结果会显示在输入框下方：`已生成 N 个时间块（本地规则/DEEPSEEK）`，并自动跳转到时间块所在周并高亮它 2 秒。若有冲突会弹窗列出被跳过的时间块。

**解析机制**：未配置 AI 服务商时用内置本地中文规则（即时返回）；在设置里选 OpenAI/DeepSeek 并填入自己的 Key 后走 AI 解析（约几秒）。输入没有时间安排或语义不明时会被拒答并提示原因。

新生成的时间块默认带**提前 5 分钟的微信提醒**。

### 3.1.1 语音输入

输入框右侧的麦克风按钮：**点一下开始录音，再点一下结束**并自动识别，识别出的文字会**追加**到输入框里（不会覆盖你已经打的字），确认或修改后再点「生成」。

- 录音中麦克风变红并有呼吸光环，按钮下方显示已录时长；最长 60 秒，到时自动停止
- 识别中图标转圈，识别完成后文字出现在输入框
- 任务看板的 AI 拆解输入框有同一个按钮，用法一致

**使用前提**：需要后端配置语音识别 Key（见「开发与部署信息」）。未配置时点按钮会提示「语音输入暂不可用」。

**注意**：

- 浏览器会弹出麦克风授权请求，需要点「允许」；拒绝后需在地址栏的权限设置里重新放行
- 页面必须是 HTTPS 或 localhost（本地开发和线上部署都满足）
- 录音会上传到后端并转发给第三方语音服务做识别，涉及隐私内容请谨慎
- 识别结果可能有个别错字（尤其人名、专有名词），建议提交前扫一眼

### 3.2 时间轴操作

周计划主体是 7 天 × 24 小时的时间轴，今天所在列有底色高亮。

| 操作 | 方式 |
|---|---|
| 新建时间块 | 点击某天空白处（开始时间按 15 分钟对齐），或点副导航的「新建时间块」 |
| 移动时间块 | 按住时间块拖动到其他时段/日期 |
| 调整时长 | 拖动时间块上/下边缘的手柄 |
| 编辑 | 点击时间块（不拖动）打开编辑弹窗 |
| 完成打卡 | 点击时间块上的圆圈按钮（完成后半透明显示） |
| 批量删除 | 副导航「批量操作」→ 勾选多个时间块 → 删除（再点「取消批量」退出） |
| 折叠空白时段 | 点击左侧时间列的「折叠」区域（按住拖动选择区间，也可点开折叠对话框设置）；顶部可「重置所有折叠」 |
| 切换周 | 副导航「上周 / 本周 / 下周」 |

**待排期时间块**（看板拖入、今日视图「排到今天」产生）以青色小 chip 显示在对应日期的列头（周计划）或待办区（今日视图），标题为「待定时间」。直接把它拖到时间轴的某个位置即为它分配时间，或点击打开弹窗补时间。

编辑弹窗（「新建时间块 / 编辑时间块」）字段：

- **事项**、**开始日期/时间**、**结束日期/时间**（结束日期晚于开始日期即为跨天时间块）
- **类目**（工作/学习/健身/生活/休息，决定时间块颜色与统计归属）
- **地点**、**关联任务**（下拉选择；关联子任务时其截止日期会显示在下方，逾期标红提醒）。任务还不存在时，点下拉下方的「**＋ 新建任务**」直接输入任务名回车（或点「创建」）即可新建并自动选中——新任务会同步出现在任务看板左侧列表，保存时间块后自动在该任务下生成同名子任务；按 Esc 先退出新建输入，再按一次才关闭弹窗
- **Obsidian 关联**：粘贴 `obsidian://` 链接自动拆出知识库与笔记路径；或分别填「知识库」和「笔记路径」。有 Obsidian 关联的时间块上会出现书本图标，点击直接跳转到对应笔记
- **微信提醒**：日期时间选择器，默认开始前 5 分钟，**留空则不提醒**
- **标记为完成**：勾选后保存即完成

## 4. 任务看板视图

任务看板是「宏观目标 → 任务/子任务 → 排期」的执行入口，左侧是任务列表，右侧是日期网格（以周为列，**默认展示本周起 4 周**，今天与后续日期始终在窗口内；今天起 14 天是 AI 规划的主要范围）。有更早的历史任务/时间块时，本周之前的周以**折叠条**形式保留在最左侧，点开即可查看或拖入排期。

### 4.1 新建任务

- **手动**：点「新建任务」，填写任务名称、排期日期（选填）、状态、**任务象限**（紧急且重要/重要但不紧急/紧急但不重要/既不紧急也不重要——对应今日视图的四象限）、子任务清单（子任务可单独填**截止日期**，选填；逾期会标红）。
- **AI 拆解**：顶部输入框输入宏观计划（**一行一个目标**），如：
  ```
  做一期视频
  写AI应用文章
  ```
  点「拆解」，AI 会生成对应的任务与子任务，并把提取到的截止日期填入子任务。拆解结果会显示在下方。这个输入框同样支持**语音输入**（右侧麦克风按钮，用法见 §3.1.1）。

### 4.2 任务列表操作

- 任务行可**上下拖动排序**；点「置顶」图标把重要任务固定在最上面（置顶任务之间保持手动拖动顺序）
- **未置顶任务按四象限自动排列**：紧急且重要 → 紧急但不重要 → 重要但不紧急 → 既不紧急也不重要（同象限内保持手动顺序；象限在任务详情里改；跨象限拖动不生效，松手后页面中央会弹出琥珀色提醒）
- 勾选任务圆圈＝**完成**：会先弹出确认框，点「确认完成」才生效（取消、Esc 或点弹窗外任意处都不会变更）；已完成任务沉底显示，其子任务默认折叠，可点开；再次点击圆圈立即恢复未完成（无需确认）
- 任务行左侧的色点表示四象限；点击任务行打开详情编辑
- 子任务行各自有勾选圆圈（完成状态与对应时间块双向同步）

### 4.3 排期

- **拖动任务行到右侧任意日期列**：把整个任务排到该天（生成一个「待定时间」的时间块，之后到周计划补具体时间；若任务行已经排过日，则是改日期）
- **拖拽子任务到日期列**：只把该子任务排到那天
- 日期网格里的时间块：点击编辑、圆圈完成、书本图标打开 Obsidian；跨天时间块按天分段显示
- 点击周列头可折叠/展开该周（本周之前的历史周默认折叠）；**右键（移动端长按）周列头可隐藏该周显示**，隐藏后表头最左端会出现「N 周已隐藏」窄条（固定在任务列旁），点击即可恢复显示；**向右滚动到尽头会自动追加更多周**。追加的周数与折叠/展开状态会记住，刷新页面永远回到从本周起的窗口

### 4.4 AI 规划

副导航的「AI 规划」按钮为当前所有任务自动生成时间块。规则：

- 只安排**有子任务且未完成**的子任务；没有子任务的任务不参与
- 规划窗口是**今天起 14 天**；已有安排会避让，冲突的时间块跳过并在提示里报数量
- 尊重**子任务截止日期**（硬约束）
- 参考**记忆系统**里的偏好习惯（软偏好）与**长期约束**（硬约束，如「9 点前不安排」）
- 按设置里的**规划风格/权重/时段偏好**评分选时；优先把「紧急且重要」象限的任务按高优先级对待

没有可规划的子任务时按钮置灰并提示「请先添加任务 / 请添加未完成的子任务」。

## 5. 今日待办视图

今日视图是「今天做什么」的仪表盘：顶部四个统计卡（今日安排数、完成进度、待办任务数、明日安排数），移动端为单列、桌面端为双栏。

- **今日安排**：今天的所有时间块，按时间排序。每行：时间、事项、地点、类目、完成圆圈（点击打卡）；带 Obsidian 的时间块有跳转按钮。点击行打开编辑弹窗
- **待排期**：今天范围内「待定时间」的时间块单独一行显示，点击补时间
- **待办 · 四象限**：把**所有任务下未完成的子任务**按任务象限分组展示（紧急且重要 → 重要 → 紧急 → 既不紧急），勾选即完成（与看板/时间块状态同步）；「排到今天」按钮把该子任务生成一个今天的待排期时间块
- **明日预览**：明天的安排一览

## 6. 统计周报视图

按当前选中周统计：

- **本周投入 / 完成时长 / 完成率**（环形图）/ **本周时间块 / 待排期**四个概览卡
- **类目时长统计**：各类目投入时长与占比条
- **本周 24 小时分布**：7 天的时间分布条
- **Obsidian 周报**：自动生成的 Markdown 周报（类目时长、完成率、逐日安排），可**复制**或**下载 .md** 文件

副导航的「导出 Markdown」按钮为灰（由周报卡内的复制/下载承担）。顶部副导航可切换上一周/本周/下一周。

## 7. 记忆系统

入口：页脚「记忆系统」，或 设置 → 记忆系统 →「管理记忆」。

记忆分四类：**时间偏好**（如「我上午的精力最好」）、**习惯**（如「每周运动两次」）、**生活/工作偏好**（如「深度任务安排在上午」）、**长期约束**（如「周末不安排工作」——AI 规划会把它当硬约束）。

- **手动管理**：每个分类点「+」添加；记忆卡片上可**编辑 / 归档（电源图标，可恢复）/ 删除**；底部开关可切换是否显示已归档（归档只影响 AI 规划，删除彻底移除）
- **智能分析**：点「候选记忆」区的「智能分析」按钮，系统回溯最近 14 天的时间块数据（**纯本地统计，不发外部请求**），生成候选记忆建议，每条带**置信度**与**依据**说明。点「加入我的记忆」采纳（内容重复时提示“已经添加过”），点「忽略」放弃
- 数据量不足或没发现规律时，会提示原因而不是硬编建议

哪些记忆参与 AI 拆解/规划：未归档的记忆全部作为参考（软偏好），其中「长期约束」类别作为硬约束（如“9 点前不安排”）。

## 8. 设置

入口：顶部齿轮或页脚「设置」。

- **Obsidian 知识库**：填知识库名称，或直接粘贴一条 `obsidian://` 链接自动提取
- **AI 解析服务**：OpenAI / DeepSeek / 本地规则 三选一。选 AI 服务商时必须填入**你自己的 API Key**（仅保存在你的账号数据里，随请求传给后端），不填无法保存会红字提示；改回「本地规则」即可不填。未配置 Key 时所有 AI 功能自动回退本地规则
- **个性化规划**：
  - 规划风格四选一：均衡推荐 / 深度专注 / 截止优先 / 稳妥安排 / 负荷可控
  - 「重点加强」：在风格基础上最多再强调 2 个维度（记忆、理解、时间、优先级、冲突、负荷）
  - 「高级权重设置」：展开后可逐项滑杆/数字微调六维权重（改一项其余按比例重新分配，总和恒为 100%）；有「恢复均衡默认」一键还原
- **时段偏好**：均衡 / 早起型（清晨为黄金时段）/ 夜猫型（晚上效率更高）——影响 AI 规划对各时段的评分

## 9. 账号与云同步

- 点顶部「登录」打开登录/注册（Supabase Auth，邮箱+密码）；登录后顶部显示邮箱与「云端同步」，数据自动上传
- 点邮箱（或页脚「账号」）可查看账号、退出登录（退出后回到本地模式，本地数据保留）
- 登录后提醒功能才开始生效（见下节）

## 10. 定时提醒（微信推送）

- **前提**：登录账号且数据已同步到云端（本地模式不触发提醒）；环境里配置了任一路推送通道
- **设置提醒**：在时间块弹窗的「微信提醒」填提醒时间（默认自动填开始前 5 分钟，改动后不再跟随；留空不提醒）
- **触发**：生产环境每 5 分钟扫描一次（每日 4 次扫描任务换班间隙约一刻钟不扫描），到点推送微信消息（含事项名、日期、时间、地点）
- **迟到的提醒不补发**：提醒时间已过 10 分钟以上不再推送（去重，同一时间块只推一次）
- 推送通道：企业微信机器人 / PushPlus / Server酱（部署时配置，见 [operations.md](operations.md) §2）

## 11. 常见问题

| 现象 | 说明 |
|---|---|
| 左上角有「展示数据」 | 没有本地数据时的演示数据，新建内容后会覆盖 |
| 「导出日历」按钮是灰的 | ICS 导出功能暂未启用（已取消） |
| 提醒没收到 | 先确认已登录（右上角「云端同步」）、时间块有提醒时间、通道已配置。本地模式不提醒 |
| 换电脑数据不见了 | 本地模式数据只在当前浏览器；要跨设备请登录云同步 |
| 输入自然语言被拒 | 句子要包含时间和事项（如「周二下午2点到5点写代码」）；无意义的输入会明确拒答 |
| AI 规划结果不满意 | 在设置里调整风格/时段偏好，或补充记忆（如习惯、约束）后重试 |
| 时间块拖不进周计划？ | 待排期 chip 拖到时间轴释放即为排期；也可点开弹窗直接填时间 |
| 语音按钮点了没反应？ | 后端未配 `SILICONFLOW_API_KEY` 会提示「语音输入暂不可用」；另需允许浏览器麦克风权限，且页面为 HTTPS 或 localhost |
| 语音识别结果有错字 | 人名、专有名词容易识别偏差，提交前扫一眼手动改；识别文本是追加到输入框的，不会覆盖已打内容 |
| 隐私 | AI 解析/拆解会把输入文本发送到 OpenAI/DeepSeek，语音识别会把录音发送到 SiliconFlow，提醒内容发送到微信通道，注意不要输入敏感信息 |
