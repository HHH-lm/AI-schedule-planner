## 新增能力

- `backend/app/logging_setup.py`：JSON Lines 格式化（`time/level/logger/event` + 事件字段）、`setup_logging`（幂等，`LOG_LEVEL`/`LOG_FORMAT` 可配）、`log_event` 埋点助手、`request_id` ContextVar。
- `backend/app/main.py`：启动时初始化日志；HTTP 中间件记录 `http.request`（method/path/status/duration_ms），`request_id` 贯穿请求。
- `backend/app/services/ai.py`：`call_chat_completions` 增加 `operation` 参数并记录 `ai.request` / `ai.response` / `ai.timeout` / `ai.error`（provider/model/operation/duration_ms/status）。
- `backend/app/services/push.py`：`push.request` / `push.success` / `push.failure`（含 PushPlus 业务错误码 code）。
- `backend/app/services/reminders.py`：`reminder.scan.start/due/done`、`reminder.push.failed/skipped`、`reminder.scan.error`；fetch 异常不再 500，而是记录事件并安全返回；scan_id 作 request_id。
- `backend/app/services/planner_v2.py`、`planner.py`：`plan_v2.start/result`、`breakdown.start/result`（source/blocks/tasks 数量）。
- `backend/app/routers/parse.py`、`match_task.py`：`parse.result`、`match_task.start/result/error`（原 `except Exception: pass` 静默吞错改为记录 `match_task.error`）。
- `backend/tests/test_observability.py`：16 个测试覆盖 JSON 格式、request_id、HTTP 中间件、AI 超时/错误/成功、推送成功/失败/PushPlus 业务错误码、提醒扫描事件、match-task 失败回退。
- `.env.example` / `docs/operations.md`（新增第 4 节“日志与可观测性”）/ `README.md`：日志配置、事件清单与排查示例。

## 隐私与安全约定

- 日志只记录脱敏元数据（长度、数量、状态码、耗时、错误类型/截断信息），不记录自然语言输入、日程文本、推送令牌与 API Key；`request_id` 仅用于关联，不含用户身份信息。
- 未引入外部日志服务依赖。
