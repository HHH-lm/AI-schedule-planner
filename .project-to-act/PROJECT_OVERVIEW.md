## 项目目标

- 初步目标（来源：README，待用户确认）：让用户以自然语言描述计划，系统将其拆解为可执行的周计划与宏观任务看板，并通过统计周报跟踪执行结果。

## 范围

### 包含

- 周计划视图：24 小时时间轴、拖拽移动与拉伸、完成打卡、地点标注、类目颜色区分。
- 自然语言生成：中文句子自动解析为时间块。
- 宏观任务看板：任务列表与 14 天日期网格、拖拽排期、子任务拆解、任务与时间块双向联动。
- 今日待办视图：移动端单列卡片流、桌面端双栏仪表盘，展示今日安排、待办任务与明日预览，支持完成打卡与“排到今天”。
- 待办四象限：所有待办按紧急/重要矩阵分为四类（紧急且重要、重要但不紧急、紧急但不重要、既不紧急也不重要），新建任务时选择象限。
- 定时提醒：时间块可设置提醒时间，FastAPI 后端 APScheduler 每 5 分钟扫描并推送到微信（企业微信机器人 / PushPlus / Server酱），推送记录写入 `reminder_log` 去重。
- 待排期任务拖拽：未排期任务可拖到其所在日期的时间网格，按 15 分钟刻度落点。
- 点击空白新建：点击时间轴空白处弹出新建时间块，自动预填日期与开始时间。
- Obsidian 关联与跳转：时间块支持粘贴 Obsidian 链接自动解析，并跳转 `obsidian://open`。
- 撤销/重做：三段式历史栈（最多 50 步），支持 `⌘Z` / `⇧⌘Z` / `Ctrl+Y` 与页面按钮。
- 统计周报：类目时长统计、24 小时时间分布、完成率、Markdown 导出。
- 数据层：localStorage 默认，Supabase 可选同步；AI 任务解析、任务拆解、时间规划、冲突检测与 AI 调用由 FastAPI 后端（Python）实现，未配置 Key 时由后端回退本地中文 NLP 规则。

### 非目标

- 尚未与用户确认；README 中列出的后续计划（如 macOS 桌面版、Obsidian 插件双向同步、PWA 离线缓存）当前不主动纳入里程碑。
- ICS 导出：按用户要求暂缓，相关代码已注释、按钮置灰，后续再评估恢复。

## 技术路线与关键约束

- 框架：Next.js 15 + React 19。
- 后端：FastAPI + Python 3.12+，承载自然语言解析、任务拆解、时间规划、冲突检测、AI 调用与定时提醒。
- 样式：Tailwind CSS 4。
- 图标：Lucide React。
- 数据层：localStorage（默认） / Supabase（可选）。
- AI 解析：OpenAI / DeepSeek API（FastAPI 服务端），未配置时回退后端本地中文 NLP 规则。

## 数据与安全边界

- 数据分类：
   - 用户身份：邮箱、密码哈希 — 🔴 高敏感，仅存 Supabase Auth，不落本地日志
   - 推送令牌：企业微信 / PushPlus / Server酱 Key — 🔴 高敏感，仅存服务端环境变量
   - 日程数据：时间块、任务、待办 — 🟡 中敏感，localStorage 本地 / Supabase RLS 隔离
   - 记忆偏好：用户主动管理的工作/生活偏好 — 🟡 中敏感，仅服务端暂存，前端引用
   - AI 配置：提供商选择、主题设置 — 🟢 低敏感，localStorage 本地
   - 应用配置：版本号、类目颜色 — 🟢 低敏感，可公开
- 敏感信息处理：只记录脱敏摘要、证据 ID 和受控位置，不粘贴原始敏感数据。
